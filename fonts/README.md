The profile header is generated from these local font files. Its SVG contains
outlined paths, so visitors do not download the fonts and no external font
request is needed.

- `Manrope-Light.ttf`: Manrope, Google Fonts static Latin TTF.
  Source: https://fonts.gstatic.com/s/manrope/v23/xn7_YHE41ni1AdIRqAuZuw1Bx9mbZk6jFO_F.ttf
  Upstream: https://github.com/google/fonts/tree/main/ofl/manrope
  License: `OFL-Manrope.txt`.
- `Newsreader-LightItalic.ttf`: Newsreader Light Italic, Google Fonts static Latin TTF.
  Source: https://fonts.gstatic.com/s/newsreader/v26/cY9kfjOCX1hbuyalUrK439vogqC9yFZCYg7oRYaIP4obnf7fTXglsMx2T-ZA.ttf
  Upstream: https://github.com/google/fonts/tree/main/ofl/newsreader
  License: `OFL-Newsreader.txt`.

The TTF bytes are unchanged from the official Google Fonts downloads used for
the portfolio's LinkedIn banner. The SIL Open Font License applies to the font
files; it does not change the license of the generated artwork.
